# Scarlight - Öncelikli Özellikler (+18 Odaklı)

## ✅ Hemen Eklenecekler

### 1. Kademeli Yoğunluk Sistemi 🔥 (EN ÖNEMLİ)
```
Soft → Medium → Ateşli → Hardcore

- Her seviye 10-15 başarılı tur sonra unlock
- Manuel geçiş butonu
- Kartlar seviyeye göre filtrelenir
- Görsel gösterge (progress bar)
```

**Faydası:**
- Oyun doğal ilerler (ani yoğunluk yok)
- Herkes kendi hızında
- Daha rahat başlangıç
- Yoğunluk kontrollü artış

---

### 2. Joker/Pas Hakkı Sistemi ⭐
```
- Her oyuncu 3 joker
- Joker kullan = ceza yok, sonraki karta geç
- Joker bitince normal pas (ceza gelir)
- UI'da joker sayısı göster
```

**Faydası:**
- Oyuncular rahat hisseder
- "Çok zorsa atla" güvenliği
- Stratejik kullanım

---

### 3. Sürpriz Görev Tetikleme ⚡
```
Soru:
A) Evet
B) Hayır

→ B seçilirse sürpriz görev aktive!
"Şimdi 30 saniye içinde..."
```

**Faydası:**
- Unexpected twists
- Oyun heyecanı
- Seçimlerin sonucu var

---

### 4. Hızlı Başlatma 🚀
```
- "Son Oyuncularla Oyna" butonu
- PlayerSetup'ı atla
- Direkt oyuna gir
```

**Faydası:**
- Tekrar oynarken hız
- Daha az tıklama

---

### 5. Kart Filtreleme 🎴
```
Oyun başında seç:
□ Görevler
□ Sorular
□ Dengeli (her ikisi)
□ Çark dahil/hariç
```

**Faydası:**
- Kullanıcı kontrolü
- Tercih odaklı oyun

---

### 6. Minimal İstatistikler 📊
```
Oyun sonunda:
- Süre: 45 dakika
- Tamamlanan: 28
- Pas geçilen: 5
- Joker kullanılan: 4
- Seviye: Ateşli'ye ulaşıldı
```

**Faydası:**
- Başarı hissi
- Oyun geçmişi

---

### 7. Ses Efektleri 🔊
```
- Timer tick (son 5 sn)
- Success sound
- Fail/pass sound
- Wheel spin
- Seviye atlama sound
- Ambient (seviyeye göre değişir)
```

**Faydası:**
- İmmersion
- Premium his
- Tension builder

---

### 8. Süre Kontrolü ⏱️
```
Timer çalışırken:
- "+30 saniye" butonu (1 kez/kart)
- İhtiyaç anında esneklik
```

**Faydası:**
- Zorlanınca ekstra süre
- Daha az stres
